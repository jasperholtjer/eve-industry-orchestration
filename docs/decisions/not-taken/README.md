# Not taken — orchestration

An idea that was considered and declined, written down so it stays declined —
or gets re-opened on purpose, with evidence, instead of by forgetting.

The shape, what earns a file, and how to re-open one are the platform's, at
[`../../../../not-taken/README.md`](../../../../not-taken/README.md): a dated
`YYYY-MM-DD-<slug>.md` with four headings — `# <the idea>`, `## What it would
have been`, `## Why not`, `## What would change our mind` — and the first line
under the last two has to stand alone, because that is what `candidates`
prints. The test for *here* rather than *there* is where the thing would have
been built.

`candidates` prints this folder last, after `DEFERRED IN THE ADRS`. Without
that read this is furniture.

## The one boundary that is orchestration's

**What belongs to another repository is not declined here, it is handed over.**
A candidate whose answer is compute, parsing or validation in Python is a
corpus row: name it and stop. `ROADMAP.md`'s *Out of scope* already carries the
two standing cases — the contract itself, and homelab provisioning — and it
stays there, because those are ownership facts rather than ideas anyone
weighed. This folder is for what *would* have been built in this repository and
was turned down: a convention, a tool, an orchestration shape argued for and
refused.
